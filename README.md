🍔 Burger Hut – Full-Stack Fast Food Ordering Website
📌 Description

A full-stack PHP & MySQL food ordering system with complete user + admin functionality. Users can register, log in, browse menus, place orders, and leave testimonials. Admins control everything—manage users, products, orders, testimonials, settings, and view sales analytics. Integrated with Stripe payments, WhatsApp notifications, and Chart.js dashboards.

🚀 Features

User Side

Register/login, manage profile

Browse menu & place food orders

Cart & checkout (Stripe integrated)

Order confirmation via WhatsApp & Email

Submit ratings & testimonials

Admin Side

Dashboard with income & sales charts (Chart.js)

Manage users, products, orders, settings

Approve testimonials before publishing

CRUD operations (Add/Update/Delete)

View total income & order history

🛠️ Tech Stack

Frontend: HTML, CSS, Bootstrap, JavaScript

Backend: PHP, MySQL

Integrations: Stripe, WhatsApp API, PHPMailer, EmailJS, Chart.js
